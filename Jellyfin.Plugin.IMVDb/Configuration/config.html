IMVDb Api Key
How many requests per minute the plugin may send to IMVDb. IMVDb allows at most 1000 per minute per API key, shared by everything using that key. Leave this at the default unless IMVDb has granted you a different allowance.
How long a response from IMVDb is reused before it is fetched again. IMVDb asks that applications cache rather than request a higher rate limit, so caching cannot be disabled.
